# تسيير المخزون والصندوق

تطبيق أندرويد لتسيير مخزون وصندوق المحلات التجارية، يعمل دون إنترنت.

- إدخال البضاعة (شراء) وبيعها بالكود بار عن طريق الكاميرا فقط
- حساب دقيق للمخزون وحركة الصندوق (بيع، شراء، مصاريف)
- عدة محلات تجارية، لكل محل تفعيله الخاص

يُبنى ملف APK تلقائيًا في GitHub Actions عند كل تحديث (تبويب Actions ← آخر تشغيل ← makhzan-apk).
